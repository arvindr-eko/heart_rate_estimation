re-derivation (much better statistical power: 26,083 samples/combo vs ~314).

METHOD: for each of the 23 DSP parameters, against each of 4 outcomes (display_rate = 1 -
no_display fraction, half_rate, double_rate, correct_rate):
  - Pearson correlation (r) across the 256 combos -- captures LINEAR/monotonic direction.
  - Random Forest feature importance (500 trees, depth 6) -- captures non-linear/interaction
    effects a correlation can miss entirely (a parameter can matter a lot with importance
    high but correlation near 0, if its effect is non-monotonic -- e.g. a middle-value sweet
    spot). RF importance is the PRIMARY significance ranking below; correlation supplies the
    directional lever description where the relationship is reasonably monotonic.
  - Tercile comparison: mean outcome in the lowest-third vs highest-third of that parameter's
    values across the actual 256 sampled combos (not synthetic values) -- a concrete,
    assumption-free 'what actually happened when this was low vs high' readout.

CAVEAT: this is purely observational/correlational across a RANDOM sweep, not a controlled
ablation -- parameters can be correlated with each other by chance in a finite random sample,
so a lever identified here should be validated with a targeted follow-up sweep (hold other
params fixed, vary this one deliberately) before fully trusting the causal direction.
